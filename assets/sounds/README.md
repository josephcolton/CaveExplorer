# Cave Explorer sound effects

`data/sounds.json` says which file plays for each game event (jump, swing, coin, ...). To change
a sound, drop a new file in this folder and point the event at it there.

Every sound here is **CC0** (public domain). Credit isn't required, but we give it anyway:

| Files | Pack | Author | Download |
|-------|------|--------|----------|
| `*.ogg` (blade, creature, item, wood, stones, metal, lock, book) | 80 CC0 RPG SFX | rubberduck | https://opengameart.org/content/80-cc0-rpg-sfx |
| `sfx_*.wav` | The Essential Retro Video Game Sound Effects Collection [512 sounds] | Juhani Junkala (SubspaceAudio) | https://opengameart.org/content/512-sound-effects-8-bit-style |

The files keep their original names so they can be traced back to their packs.
